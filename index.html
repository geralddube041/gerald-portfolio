Windows Server & Active Directory

Completed Infrastructure & System Administration Lab

Built and configured a Windows Server lab environment using Active Directory Domain Services. The project included server configuration, Organizational Units, user and group management, password and account lockout policies, DNS and DHCP services, domain-joining a Windows client, and testing domain authentication.

01 — Server Manager Dashboard

Used Server Manager to manage the Windows Server environment and review the installed server roles and services.

02 — Local Server Configuration

Configured the server's local system and networking settings as part of the Windows Server domain infrastructure.

03 — Organizational Units

Created and organised Organizational Units to provide a structured way of managing directory objects.

04 — Users & Groups

Created and managed user accounts and security groups within the Active Directory environment.

05 — Password Policy

Configured domain password policy settings to demonstrate basic account security and authentication requirements.

06 — Account Lockout Policy

Configured account lockout settings to help protect domain accounts against repeated unsuccessful authentication attempts.

07 — DHCP

Configured DHCP services to provide network addressing and configuration to client machines within the lab environment.

08 — DNS

Configured and tested DNS to support domain name resolution within the Windows Server and Active Directory environment.

09 — Domain-Joined Client

Configured a Windows client machine and successfully connected it to the gerrytech.com domain.

10 — Domain Login

Tested domain authentication by signing into the client using an Active Directory domain account.
