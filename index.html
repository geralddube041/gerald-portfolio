Network Infrastructure Lab

Completed Cisco Networking & Infrastructure Lab

Designed and implemented a simulated small-business network using Cisco Packet Tracer. The lab demonstrates VLAN segmentation, IPv4 addressing, access ports, 802.1Q trunking and inter-VLAN routing using a router-on-a-stick configuration.

Network Design

Built a small departmental network using one Cisco 2911 router, one Cisco 2960 switch and four client PCs.

VLAN Segmentation

Created four VLANs representing IT, HR, Sales and Finance departments to logically separate network traffic.

IPv4 Addressing

Assigned separate /24 networks to each department and configured default gateways for the client devices.

Access Ports

Configured switch access ports and assigned client devices to their appropriate departmental VLANs.

802.1Q Trunking

Configured the switch-to-router connection as a trunk capable of carrying the required VLAN traffic.

Router-on-a-Stick

Created router subinterfaces for VLAN 10, 20, 30 and 40, providing each VLAN with its own default gateway.

Inter-VLAN Routing

Enabled communication between different departmental networks through the router.

Connectivity Testing

Tested gateway connectivity and communication between hosts in different VLANs using ping.

Network addressing: IT — 192.168.10.0/24 | HR — 192.168.20.0/24 | Sales — 192.168.30.0/24 | Finance — 192.168.40.0/24
